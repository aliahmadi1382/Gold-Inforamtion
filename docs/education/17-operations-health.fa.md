# فصل ۱۷ — سلامت اجرا با تازگی داده فرق دارد

ممکن است دریافت موفق باشد، اما آخرین دورهٔ داده قدیمی باشد. ممکن است گزارش قابل ساخت باشد، اما دریافت CFTC شکست خورده باشد. فصل قبل داده را برای بازیابی محافظت کرد؛ این فصل اسناد عملیات را کنار هم می‌گذارد تا بدانیم کدام اجرا نیاز به بررسی دارد.

## سه سؤال متفاوت

۱. عملیات تمام شده؟ سند دریافت `running`، `succeeded` یا `failed` را نشان می‌دهد.

۲. بازار به‌روز است؟ زمان مرجع، انتشار و محدودیت روش باید جدا بررسی شوند؛ گزارش سلامت عملیات این سؤال را پاسخ نمی‌دهد.

۳. سهمیه باقی مانده؟ بدون شاهد درخواست و پاسخ منبع نمی‌دانیم. تعداد اسناد دریافت، تعداد درخواست‌های شبکه نیست.

## تمرین آفلاین

```powershell
uv run gold --store local/market operations-health --output-dir local/operations-health/lesson17
```

JSON و متن فارسی را بخوانید. `attention` را با شکست ساخت گزارش اشتباه نگیرید: گزارش ساخته شده و نیاز به بررسی را نشان می‌دهد. کد خروج سه همین وضعیت را برای ابزارهای دیگر مشخص می‌کند. پوشهٔ تمرین را دوباره استفاده نکنید؛ هر snapshot یک پوشهٔ جدید دارد.

یک شکست قدیمی که بعداً در همان جریان موفق شده، به‌تنهایی وضعیت جاری را خراب نمی‌کند. اما اجرای ناتمام حتی با موفقیت جدیدتر دیده می‌شود: شاید فرایند قبلی قطع شده باشد و هنوز شواهدش نیاز به بررسی داشته باشند. فرمان آن را خودکار حذف یا شکست‌خورده اعلام نمی‌کند.

## چرا 403 را فوراً تکرار نمی‌کنیم؟

403 می‌تواند مانع دسترسی باشد؛ تکرار یک درخواست یکسان لزوماً کمک نمی‌کند. 429 نیاز به بررسی سهمیه دارد. خطای اتصال یا 503 ممکن است موقت باشد، اما انتقال شبکه از قبل حداکثر سه تلاش کرده است؛ گزارش تلاش چهارم را خودکار انجام نمی‌دهد. این تفاوت از مصرف بی‌دلیل سهمیه جلوگیری می‌کند.

برای علت دقیق‌تر، manifest یک refresh را صریح متصل کنید. در انتقال دستگاه، مسیر قدیمی را تغییر ندهید؛ گزینهٔ `--allow-relocated-refresh` همراه کنترل شواهد استفاده می‌شود. بدون این پیوند، نام `ValueError` برای ادعای HTTP 403 کافی نیست.

## نسخهٔ Python برای کدام اجراست؟

Python ثبت‌شده در گزارش، محیط ساخت همین snapshot است. محیط دریافت‌های قدیمی ثبت نشده و نامعلوم می‌ماند. درس بازیابی را به خاطر بیاورید: تفاوت Python می‌تواند دقت بسیار کوچک محاسبات را تغییر دهد؛ برای بازتولید پژوهش باید محیط همان پژوهش را حفظ کنیم.

روش و محدودیت‌های کامل در [سلامت عملیات](../source-methodology/operations-health.fa.md) آمده‌اند.
