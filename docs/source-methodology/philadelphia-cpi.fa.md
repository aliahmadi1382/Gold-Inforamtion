# شواهد انتشار اولیهٔ CPI — تحویل ۰٫۲۳

[منبع رسمی فدرال‌رزرو فیلادلفیا](https://www.philadelphiafed.org/surveys-and-data/real-time-data-research/pcpi) فایل برآورد انتشار اول، دوم، سوم و آخرین نسخهٔ CPI را ارائه می‌کند. [روش رسمی](https://www.philadelphiafed.org/-/media/FRBP/Assets/Surveys-And-Data/real-time-data/data-files/documentation/Documentation_First_Second_Third_Release_Values.pdf) از انتخاب vintageهای ماهانه استفاده می‌کند و دربارهٔ تغییر برنامه و تأخیر انتشار محدودیت دارد؛ «First» ساعت اندازه‌گیری‌شدهٔ اولین تحویل نیست.

## دریافت واقعی و قرارداد

در ۸ اکتبر ۲۰۲۶ فایل واقعی دریافت و خام با SHA-256 محفوظ شد. ۳۳۵ ماه از اکتبر ۱۹۹۸ تا اوت ۲۰۲۶ و چهار مرحله، ۱٬۳۴۰ نسخهٔ مشاهده ساختند؛ موجودی کل ۹۶٬۸۵۳ نسخه است. انتشار اول و آخرین نسخه هر کدام ۳۳۳ مقدار و دو مقدار مفقود دارند؛ دوم و سوم هر کدام ۳۳۵ مقدار مفقود دارند. مقدار مفقود با صفر یا نسخهٔ دیگر جایگزین نمی‌شود. تاریخ به دورهٔ اقتصادی تعلق دارد؛ available_at زمان دریافت این پروژه است و vintage_date جعل نمی‌شود.

واحد بومی «رشد ماهانه با نرخ سالانه‌شده، درصد، تعدیل فصلی» است. فایل در NOTES تاریخ به‌روزرسانی ۱۱ سپتامبر ۲۰۲۶ دارد؛ زمان صفحه یا زمان دریافت، تاریخ به‌روزرسانی فایل را تغییر نمی‌دهد. اطلاعات منبع، واحد، سرستون، ترتیب/یکتایی ماه و محدودهٔ workbook پیش از ورود بررسی می‌شوند.

برای مقایسهٔ محدود با مقدار ماهانهٔ BLS، تبدیل دقیق این است:

`monthly_percent = 100*((1+annualized_percent/100)**(1/12)-1)`

تقسیم ساده بر ۱۲ استفاده نشده است. هشت مقدار headline منتخب با اسناد BLS در دقت یک اعشار سازگار بودند. دورهٔ قبلی درج‌شده در سند به‌عنوان انتشار اول آن دوره مقایسه نشده است. هر دو مسیر از BLS می‌آیند؛ رأی دو منبع مستقل نیستند. قیمت، غافلگیری و ساعت دسترسی از آن نتیجه نمی‌شود.

## اجرا

```powershell
$env:PYTHONUTF8 = "1"
uv run gold fetch-philly-cpi
uv run python scripts/inspect_philly_cpi.py --as-of 2026-10-08T13:50:00+00:00 --output local/pcpi-review-new.json
```

دستور دریافت دستی است و کلید لازم ندارد. وارد refresh خودکار یا گردش ده‌مرحله‌ای قبلی نشده است. script خروجی قبلی را بازنویسی نمی‌کند؛ برای بازتولید، همان store و cutoff لازم است. چهار سری جدا با نام PHILLY_PCPI در کاوش پنل قابل انتخاب‌اند. مقدارها، XLSX، رسیدها و تطبیق‌ها خصوصی محلی باقی می‌مانند؛ حق انتشار یا آموزش از دانلود عمومی استنتاج نشده است.

عملیات fetch-philly-cpi به enum اسناد دریافت اضافه شد؛ اسناد قدیمی با کد جدید قابل خواندن‌اند. نسخهٔ قدیمی نرم‌افزار عملیات جدید را نمی‌شناسد. فایل مشاهده و قرارداد گزارش تغییر نکرده‌اند. نخستین دریافت هنگام توسعه پیش از افزایش نسخه، application_version برابر ۰٫۲۲ ثبت کرده است؛ آن سند به نسخهٔ ۰٫۲۳ بازنویسی نشده است.

## وضعیت فاز ۳

فاز ۳ **هنوز تکمیل نشده** و فعال باقی می‌ماند. روش واحد/جلسه/آخر هفتهٔ Alpha Vantage و قیمت روزانهٔ هم‌تعریف، همچنین اولین مقدار و ساعت واقعی دسترسی برای دامنهٔ کامل انتشارها باز هستند. پرسش‌های آمادهٔ Alpha Vantage ارسال نشده‌اند. LBMA/IBA بدون مجوز منبع جایگزین رایگان فرض نشده است. HistData نامزد بررسی است؛ توضیح عمومی زمان و bid به‌تنهایی واحد، تقویم کامل و مجوز مجموعه را تأیید نمی‌کند.

daily_backtest_ready و first_release_verified همچنان false هستند. معیار پایان فاز تغییر داده نشده است. این تحویل شاهد واقعی اضافه می‌کند، نه گواهی تکمیل مرحله.
