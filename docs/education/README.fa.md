# آموزش همراه پروژه

این بخش برای یادگیری هم‌زمان با ساخت پروژه است. لازم نیست همهٔ اصطلاحات را از قبل بدانید؛ هر فصل توضیح کوتاه، مثال، تمرین و ارتباط با کد دارد. اعداد مثال‌ها ساختگی‌اند و توصیهٔ معامله نیستند.

| ترتیب | فصل | نتیجهٔ یادگیری |
| --- | --- | --- |
| ۱ | [مبانی دادهٔ بازار](01-market-data.fa.md) | تفاوت XAU/USD، کندل، قیمت پایانی، منبع و واحد |
| ۲ | [کیفیت، زمان و منشأ داده](02-quality-and-time.fa.md) | خواندن گزارش کیفیت و تشخیص اطلاعات آینده، دادهٔ مفقود و اصلاحیه |
| ۳ | [راه‌اندازی منابع رایگان](03-free-data-setup.fa.md) | انتخاب مسیر داده و نگهداری درست کلید API |
| ۴ | [خواندن نخستین دادهٔ واقعی](04-first-real-data.fa.md) | تفاوت اتصال موفق، دادهٔ قابل استفاده و تأیید روش بازار |
| ۵ | [تاریخچه، شاخص‌های کلان و اصلاحیه‌ها](05-history-macro-and-revisions.fa.md) | شناخت هفت شاخص، واحد درصد، نسخهٔ تاریخی، اتصال زمانی و مقایسهٔ ماهانه |
| ۶ | [تقویم انتشار و گزارش خوانا](06-release-calendar-and-reports.fa.md) | برنامه در برابر انتشار واقعی، ساعت تابستانی، سن شاهد و خواندن گزارش پروژه |
| ۷ | [روابط ماهانه و همبستگی](07-monthly-relationships.fa.md) | سطح و تغییر، پیرسون/اسپیرمن، نمونهٔ مشترک، پنجرهٔ متحرک و مرز استنباط |
| ۸ | [مقدار انتشار و نسخهٔ تاریخی](08-release-values-and-vintages.fa.md) | سند اولیه/بازانتشار، مقدار قبلی، vintage هم‌تاریخ، دقت نمایش و تفاوت اصلاحیه با Surprise |
| ۹ | [دفتر اصلاحیه‌ها و پوشش نمونه](09-revision-ledger.fa.md) | مقایسهٔ همان دوره در دو سند، مخرج ثابت، سند مبهم، ثبت دوباره و حدود برابری عددها |
| مرجع | [واژه‌نامه](glossary.fa.md) | تعریف اصطلاحات رایج در مستندات و کد |

پس از هر فاز، فصل مرتبط به‌روز می‌شود. همبستگی توصیفی در فصل هفتم اجرا و توضیح داده شده است. آزمون خارج از نمونه، بک‌تست، ریسک و اجرای سفارش هنگام رسیدن به همان فاز با تمرین عملی تکمیل خواهند شد؛ وجود نام آن‌ها در واژه‌نامه به معنی پیاده‌سازی آن قابلیت نیست.

برای دیدن مسیر و وضعیت کار، [فازهای پروژه](../phases.fa.md) را بخوانید. برای اجرای برنامه، راهنمای [عملیات](../operations.md) مرجع است.
