# فصل ۳ — منابع رایگان و کلیدهای دسترسی

انتخاب تأییدشدهٔ شما: XAU/USD روزانه، گسترش به بازه‌های کوتاه‌تر در مراحل بعد، فقط منابع رایگان و عمومی، دریافت از API با کلیدهای شخصی Alpha Vantage و FRED. بررسی زیر در ۲۰۲۶-۱۰-۰۵ انجام شده است. رایگان بودن با حق انتشار فایل خام در GitHub یکسان نیست.

## نتیجهٔ بررسی اولیه

| منبع | کاربرد احتمالی | محدودیت فعلی |
| --- | --- | --- |
| [Alpha Vantage](https://www.alphavantage.co/documentation/) | تاریخچهٔ قیمت پایانی روزانهٔ طلا | کلید شخصی لازم است؛ این خروجی OHLC کامل نیست؛ پاسخ واقعی، پوشش و دسترسی حساب باید آزموده شوند |
| [FRED](https://fred.stlouisfed.org/docs/api/api_key.html) | نرخ بهره، بازده واقعی و متغیرهای کلان | API به کلید شخصی نیاز دارد؛ اتصال در پروژه موجود است |
| [Dukascopy Historical Export](https://www.dukascopy.com/swiss/english/marketwatch/historical/) | فایل تاریخی در بازه‌های مختلف | مسیر دانلود انسانی قابل بررسی است؛ شرایط استفادهٔ سایت، خودکارسازی را محدود می‌کند و مسیر S3 مستند آن Requester Pays است |
| [Stooq](https://stooq.com/q/d/?s=xauusd) | نامزد بررسی قیمت XAU/USD | صفحه در این محیط بررسی مرورگر خواست و دریافت CSV موفق نشد؛ منبع عملیاتی اعلام نشده است |

طبق [راهنمای Alpha Vantage](https://www.alphavantage.co/support/)، پلن رایگان عمومی محدودیت درخواست روزانه دارد. تا زمانی که پاسخ واقعی حساب بررسی نشده، تاریخ شروع داده، آخرین روز یا دسترسی کامل را تضمین نمی‌کنیم. [شرایط سرویس](https://www.alphavantage.co/terms_of_service/) نیز استفادهٔ فردی و غیرتجاری را از استفادهٔ تجاری جدا می‌کند. دادهٔ خام و نتایج وابسته به آن فعلاً محلی می‌مانند.

## راه‌اندازی مسیر انتخاب‌شده: API رایگان

۱. کلید شخصی را از [ثبت‌نام رایگان Alpha Vantage](https://www.alphavantage.co/support/#api-key) و برای داده‌های کلان از [FRED](https://fred.stlouisfed.org/docs/api/api_key.html) تهیه کنید. ثبت‌نام و پذیرش شرایط حساب با خود شماست؛ هیچ خریدی برای این فاز در نظر گرفته نشده است.

۲. در این محیط، فایل خالی `local/credentials.env` آماده شده است. در نصب تازه، فایل `.env.example` را در آن مسیر کپی کنید؛ اگر فایل از قبل کلید دارد، روی آن کپی نکنید. فقط در همان فایل محلی مقدارها را بنویسید:

```text
FRED_API_KEY=YOUR_FRED_KEY
ALPHAVANTAGE_API_KEY=YOUR_ALPHA_VANTAGE_KEY
```

کلید را در چت، README، اسکرین‌شات عمومی یا GitHub نگذارید. پوشهٔ `local/` از Git کنار گذاشته شده است. کلید خالی مجوز دسترسی ایجاد نمی‌کند. فایل نمونه عمداً کلید واقعی ندارد.

۳. بارگذاری این فایل صریح است. برای نمونه، دستور فعلی و پشتیبانی‌شدهٔ FRED:

```sh
uv run gold --credentials-file local/credentials.env fetch-fred DFII10 --start 2024-01-01 --end 2024-12-31
uv run gold runs
```

برنامه کلیدها را در گزارش عملیات نمی‌نویسد. مقدارها فقط در محیط همان اجرای دستور بارگذاری می‌شوند. در وضعیت این فصل، اتصال Alpha Vantage هنوز پیاده‌سازی نشده است؛ پس از دریافت پاسخ واقعی و بررسی قرارداد قیمت پایانی، آن را اضافه می‌کنیم. دادهٔ پایانی را به کندل مصنوعی تبدیل نخواهیم کرد.

## مسیر جایگزین در صورت نیاز به OHLC

می‌توان فایل OHLC روزانه را به‌صورت انسانی از یک منبع مجاز دریافت و همراه نام ارائه‌دهنده، نوع قیمت، منطقهٔ زمانی، تاریخ دریافت و شرایط استفاده وارد کرد. تبدیل آن به CSV مشترک باید قابل پیگیری باشد. اگر فقط قیمت پایانی وجود داشته باشد، همان محدودیت فصل ۱ اعمال می‌شود.

پس از واردکردن کلیدها، فقط بگویید «کلیدها در فایل محلی قرار گرفتند»، نه مقدار آن‌ها را. مرحلهٔ بعد، آزمون دریافت واقعی و بررسی پاسخ منبع پیش از ساخت اتصال قیمت است.
