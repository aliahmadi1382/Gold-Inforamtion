# واژه‌نامهٔ پروژه

| اصطلاح | توضیح ساده |
| --- | --- |
| XAU/USD | قیمت طلا نسبت به دلار؛ واحد و ارائه‌دهنده باید مشخص باشند |
| Spot | قیمت نقدی؛ با قرارداد آتی یا سهم صندوق یکسان نیست |
| Futures | قرارداد آتی با مشخصات و سررسید مشخص |
| ETF | صندوق قابل معامله؛ قیمت سهم و موجودی طلای آن دو دادهٔ متفاوت‌اند |
| OHLC | اولین، بیشترین، کمترین و آخرین قیمت یک بازه |
| Timeframe | طول بازهٔ کندل؛ مانند یک روز یا یک ساعت |
| Bid / Ask | قیمت پیشنهادی خرید / فروش در خوراک مشخص |
| Spread | فاصلهٔ قیمت Ask و Bid در یک زمان و منبع |
| Volume | حجم فعالیت با واحد مشخص؛ مانند قرارداد یا سهم |
| Tick | یک ثبت یا تغییر قیمت؛ الزاماً یک معامله نیست |
| Open Interest | تعداد قراردادهای مشتقهٔ باز |
| Source / Provider | منبع / ارائه‌دهندهٔ داده |
| Dataset | مجموعهٔ داده با تعریف و روش تولید مشخص |
| Stream | یک سری همگن با ابزار، منبع، واحد و بازهٔ مشخص |
| Schema | قرارداد ساختار و نوع فیلدهای داده |
| API | رابط برنامه‌نویسی برای درخواست داده یا خدمت |
| API key | کلید شناسایی دسترسی به سرویس؛ محرمانه نگهداری می‌شود |
| Raw data | فایل یا پاسخ اصلی، پیش از تبدیل |
| Normalization | تبدیل منظم به قرارداد مشترک، با حفظ اطلاعات اصلی |
| Provenance | شناسنامهٔ منشأ، زمان، واحد و مجوز هر مشاهده |
| Lineage | مسیر ارتباط نتیجه با ورودی‌ها و فایل اصلی |
| Hash / SHA-256 | اثر انگشت محتوای فایل یا رکورد برای تشخیص تغییر |
| Manifest | گزارش قابل بررسی یک عملیات ورود یا دریافت داده |
| Idempotence | تکرار همان عملیات با همان رکورد، دادهٔ تکراری نسازد |
| Atomicity | یک دستهٔ ورود، کامل ثبت شود یا ثبت نشود |
| Revision | نسخهٔ اصلاح‌شدهٔ یک مشاهده یا گزارش |
| Vintage | دیدِ داده‌ها مطابق نسخهٔ قابل دسترس در یک تاریخ مشخص |
| As-of | زمان مرجع پرسش «در آن زمان چه می‌دانستیم؟» |
| Look-ahead bias | استفادهٔ نادرست از اطلاعات آینده در تحلیل گذشته |
| Missing value | مقدار نامعلوم؛ با صفر فرق دارد |
| Freshness / Staleness | تازگی / قدیمی‌شدن داده نسبت به سیاست تعریف‌شده |
| Coverage / Gap | دامنهٔ پوشش / فاصلهٔ مشاهدات؛ فاصله لزوماً خرابی نیست |
| Synthetic | دادهٔ ساختگی برای تمرین یا آزمون نرم‌افزار |
| SMA | میانگین متحرک سادهٔ یک تعداد مشخص از قیمت‌ها |
| Momentum | اندازه‌ای از تغییر قیمت نسبت به گذشته، با تعریف دقیق پنجره |
| ATR | میانگین True Range؛ روش هموارسازی باید مشخص باشد |
| Volatility | پراکندگی تغییرات قیمت؛ جهت صعود یا نزول را تعیین نمی‌کند |
| Drawdown | افت نسبت به قلهٔ پیشین در یک مسیر مشخص |
| Backtest | آزمودن قواعد تصمیم روی گذشته، با زمان و هزینهٔ واقع‌بینانه |
| Out-of-sample | بخشی از داده که برای تنظیم روش استفاده نشده است |
| Overfitting | خوب‌شدن ظاهری روی دادهٔ آموزش بدون تعمیم قابل اتکا |
| Paper / Shadow trading | اجرای آزمایشی / مشاهدهٔ تصمیم‌ها کنار بازار بدون سفارش واقعی |
| Kill switch | سازوکار توقف اجرای سفارش در شرایط تعریف‌شده |
| CI | اجرای خودکار بررسی‌های نرم‌افزار پس از تغییر مخزن |

| Frequency | بسامد دوره‌ها؛ مثلاً روزانه یا ماهانه، مستقل از زمان انتشار |
| Seasonal adjustment / SA | تعدیل آماری الگوهای فصلی؛ NSA یعنی تعدیل‌نشده |
| Percentage point | واحد درصد؛ تغییر نرخ از ۳٪ به ۴٪ برابر یک واحد درصد است |
| Basis point / bp | نقطهٔ پایه؛ یک‌صدم واحد درصد |
| Methodology break | تغییر تعریف یا روش تولید سری؛ اتصال بی‌توضیح دو بخش می‌تواند گمراه‌کننده باشد |

این تعریف‌ها آموزشی‌اند؛ جزئیات هر معیار باید از فصل مربوط و نسخهٔ پیاده‌سازی خوانده شود.
