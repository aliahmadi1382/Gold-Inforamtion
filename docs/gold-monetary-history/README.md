# Monetary gold research

Record legal/official parity, private-market quotations, reserve holdings and convertibility rules as separate concepts. A change in a currency's gold parity is not automatically a tradable return. Archives should retain original document citation, jurisdiction, date precision, purity and monetary unit. Converting historical prices requires separately evidenced exchange rates and units, with uncertainty carried into results.

The first acquisition pass should identify archives, identify series definitions and interruptions, review reuse rights, and validate a sample against original documents. The runnable daily-price pipeline is reserved for comparable observations with explicit timestamps; it is not an OCR or historical-currency reconstruction engine.
