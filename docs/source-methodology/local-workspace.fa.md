# رابط لوکال پژوهش — نسخهٔ ۰٫۱۷

این تحویل، داده و گزارش‌های واقعی پروژه را در مرورگر نمایش می‌دهد. سرور فقط روی `127.0.0.1` گوش می‌دهد؛ داده به سرویس بیرونی فرستاده نمی‌شود. هیچ دریافت بازار، سفارش، تغییر پایگاه یا نمایش کلید از داخل پنل انجام نمی‌شود.

## باز کردن پنل

روی `Start-Local.cmd` در ریشهٔ پروژه دوبار کلیک کنید. سرور در پس‌زمینه، بدون پنجرهٔ اضافی اجرا می‌شود و پس از آماده‌شدن، مرورگر باز می‌شود. فایل‌های اجرا و رسید هویت فرایند در `local/ui-runtime/` محلی می‌مانند. روی این دستگاه محیط Python از قبل آماده است؛ برای انتقال به دستگاه تازه، Python/uv و دادهٔ محلی باید طبق handoff آماده باشند.

آدرس: **http://127.0.0.1:8765**

راه‌اندازی دوباره با دادهٔ تازه: `Restart-Local.cmd`. توقف: `Stop-Local.cmd`. راه‌انداز فقط فرایندی را متوقف می‌کند که PID، شناسهٔ اجرا و شناسهٔ workspace آن با رسید خودش و سرور فعال تطبیق داشته باشد؛ فرایند نامرتبط یا سرویس دستی بدون رسید متوقف نمی‌شود. پنجرهٔ مرورگر را بستن، سرور پس‌زمینه را متوقف نمی‌کند. هیچ اجرای خودکار هنگام روشن‌شدن ویندوز تنظیم نشده است.

برای اجرای دستی در ترمینال:

```powershell
uv run gold --store local/market local-ui
# توقف سرور دستی: Ctrl+C
# پورت دیگر:
uv run gold --store local/market local-ui --port 8766
```

CLI برای root گزارش و فازبندی نیز `--reports` و `--roadmap` می‌پذیرد. store باید وجود داشته باشد؛ اشتباه در مسیر، پایگاه تازه نمی‌سازد. راه‌انداز ویندوز از Python مستقیم استفاده می‌کند و تغییر execution policy لازم ندارد.

## پنج بخش پنل

۱. **نمای کلی:** تعداد نسخه‌ها، خام، گزارش‌های معتبر، آخرین زمان دریافت، نمودار قیمت و منابع. تعداد نسخه، تعداد مشاهدهٔ مستقل نیست. زمان دریافت با دورهٔ مرجع و زمان انتشار فرق دارد؛ دورهٔ تقویم آینده می‌تواند در منبع BLS دیده شود.

۲. **کاوش داده:** فیلتر نوع/منبع/سری، بازهٔ تاریخ، نمودار و CSV همان بازه. کلیک روی نمودار، مقدار، زمان مرجع/دسترسی/دریافت و شناسهٔ رکورد/خام را نشان می‌دهد. جدول جزئیات حداکثر ۲۰۰ مشاهدهٔ آخر بازه را دارد؛ CSV همهٔ مشاهدات بازه را حفظ می‌کند.

۳. **گزارش پژوهش:** بسته‌های قدیمی و جدید با بررسی hash و قراردادشان نمایش داده می‌شوند؛ متن فارسی به عنوان متن، تیتر و جدول امن قالب‌بندی می‌شود، نه HTML اجرایی. وضعیت هشت بخش و روابط ماهانه، با روش و نمونهٔ جدا نمایش داده می‌شوند. مقایسه‌های ذخیره‌شده از ورودی‌های همراه دوباره تأیید می‌شوند. ضریب ناموجود یا نمونهٔ ناکافی به صفر تبدیل نمی‌شود.

۴. **سلامت عملیات:** ۶۵ سند دریافت، فیلتر وضعیت، شکست متوالی، آخرین جریان، خطای امن و راهنمای اقدام. گردش آخرِ قابل اتصال از اسناد دریافت شناسایی و با قواعد ۰٫۱۶ تطبیق می‌یابد؛ انتقال مسیر تاریخی صریح در health ثبت می‌شود. سهمیه هنوز اندازه‌گیری نشده است.

۵. **مسیر پروژه:** هر هشت فاز، وضعیت، خروجی تحویل‌شده، معیار پایان و پیش‌نیاز باقی‌مانده؛ تکمیل تحویل ۰٫۱۷ با تکمیل کل فاز ۵ فرق دارد.

## قرارداد دادهٔ نمودار

هنگام شروع سرور، SQLite در حالت read-only و یک تراکنش خواندن باز می‌شود. قفل مشترک، snapshot پایگاه/اسناد دریافت/فهرست خام را در برابر نویسنده‌های پروژه هماهنگ می‌کند. اتصال پایگاه بسته می‌شود و درخواست‌های مرورگر از همین snapshot حافظه پاسخ می‌گیرند؛ فرایند writer برای تمام عمر پنل قفل نمی‌شود. برای نمایش دریافت تازه، سرویس دوباره اجرا شود؛ reload مرورگر به‌تنهایی snapshot داده را نمی‌سازد.

رکوردهای نرمال‌شده با قرارداد و hash محتوای خود خوانده می‌شوند. درون هویت دقیق هر سری، آخرین نسخه بر اساس زمان دسترسی، دریافت و شناسه تا زمان شروع پنل انتخاب می‌شود. واحد، منبع، dataset، vintage و ابعاد روش جدا می‌مانند؛ دورهٔ realtime منبع FRED در انتخاب سری مشخص است. null حفظ می‌شود و شکاف‌های بزرگ خط نمودار را قطع می‌کنند. خط بین نقاط، اندازه‌گیری روزهای بین آن‌ها نیست.

قیمت Alpha Vantage مرجع روزانه با برچسب تاریخ است، نه OHLC یا قیمت زنده. واحد استنباط‌شده روشن است. COT خالص `long-short` با واحد قرارداد است؛ پول ورودی یا سیگنال معامله نیست. روش‌های قیمت ماهانهٔ World Bank ادغام نمی‌شوند و پژوهش روابط از موتور موجود خوانده می‌شود، نه حساب تازهٔ مرورگر.

پنل audit کامل hash فایل‌های خام را اجرا نمی‌کند؛ این محدودیت در بخش عملیات و API صریح است. فهرست گزارش معتبر نیز تازه‌بودن بازار امروز را تأیید نمی‌کند؛ زمان برش گزارش کنار آن می‌آید. Host و Origin خارجی رد می‌شوند و مسیر فایل دلخواه یا فرمان نوشتن وجود ندارد. این سرور برای یک دستگاه شخصی است؛ احراز هویت چندکاربره یا انتشار اینترنتی ندارد.

## معیار پذیرش و مسیر بعد

روی دادهٔ واقعی، ۸۸٬۷۰۷ نسخه، ۷۹ خام، ۶۵ سند دریافت، ۶۵ سری با هویت مستقل، هشت گزارش و شش مقایسهٔ معتبر نمایش داده شدند. بازهٔ COT مدیریت سرمایه در سپتامبر ۲۰۲۶ پنج مشاهده دارد؛ API، نمودار و CSV مرورگر با SQL مستقل تطبیق یافتند. چیدمان دسکتاپ و نمای باریک، فیلتر، انتخاب بازه، خروجی CSV، گزارش، مقایسه و فازبندی در مرورگر بررسی شدند؛ رسید محلی `local/integration-v017/validation.json` است.

مرجع وضعیت `config/project_roadmap.json` است. پس از هر تحویل، وضعیت همان بخش به‌روز و `uv run python scripts/update_project_phases.py` اجرا می‌شود؛ تست، برابری سند فارسی و مرجع پنل را کنترل می‌کند. راهبرد و معیارهای فازهای بعد در [مسیر پروژه](../phases.fa.md) آمده‌اند. قدم بعد ثبت runtime پژوهش، شواهد درخواست/سهمیه، بررسی CFTC و دریافت تازه است؛ سپس تحلیل چندمنبعی و دروازه‌های پژوهش روزانه.
