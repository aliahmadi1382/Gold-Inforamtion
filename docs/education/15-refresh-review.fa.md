# فصل پانزدهم — مبنا، تغییر و اولویت بررسی

پس از دریافت، می‌پرسیم «چه چیزی تغییر کرده؟» و «چه چیزی باید بررسی شود؟» این‌ها یک سؤال نیستند. منبع می‌تواند امروز شکست بخورد، ولی شاهد قبلی هنوز زیر حد سن باشد. خلاصهٔ ۰٫۱۴ هر دو را جدا نشان می‌دهد.

## baseline چیست؟

Baseline گزارش مبناست. بدون آن تغییر نامعلوم است. اگر مقدار امروز ۴٫۲ است و مقدار قبلی را نداریم، افزایش یا کاهش نمی‌دانیم؛ `no_baseline` به معنی بدون تغییر نیست.

`--baseline` پوشهٔ بستهٔ پژوهش بررسی‌شده را معرفی می‌کند. در refresh بدون این گزینه، جدیدترین برش از اجراهای قبلی همان پوشه و store انتخاب می‌شود. انتخاب پیش از دریافت است. پس از انتقال دستگاه، نخستین مبنا را صریح بدهید. فایل خراب با گزارش قدیمی‌تر پنهان نمی‌شود.

## انواع تغییر

اعداد مثال ساختگی‌اند:

| قبل → بعد | برداشت |
| --- | --- |
| ۴٫۱ → ۴٫۲ | تغییر عدد با همان هویت و واحد؛ علت هنوز نیازمند بررسی است |
| ۴٫۱ → ۴٫۱ با شناسهٔ ثبت تازه | recapture یا شاهد تازه؛ مقدار ثابت است |
| سن ۲ روز → ۳ روز | شاهد قدیمی‌تر شده، بدون الزام به دریافت جدید |
| null → صفر | مقدار مفقود به صفر معلوم تبدیل شده؛ null همان صفر نیست |
| رویداد از افق گزارش خارج شده | خروج از نما؛ لغو رویداد ثابت نشده |
| قالب قبلی COT ندارد | غیرقابل مقایسه؛ نه COT صفر یا خنثی |

عدد می‌تواند تعداد رکورد، پوشش یا ضریب باشد؛ هر عدد قیمت یا خبر اقتصادی نیست. شمار فیلدهای متفاوت نیز شمار رخداد مستقل نیست.

## زمینه و اولویت

زمان برش، نسخه، تنظیمات و رجیستری جدا نمایش داده می‌شوند. تغییر روش/واحد را خودکار حرکت بازار ندانید؛ تفاضل میان هویت‌های ناسازگار ساخته نمی‌شود. وضعیت بخش‌ها قبل و بعد نیز «موجود اما محدود» را از «فاقد شواهد» جدا می‌کند.

اولویت ۱ برای خطای دریافت، گزارش، مقایسه، تازگی یا تقویم است. ۲ برای محدودیت و تغییر عدد/تعریف/زمینه است. ۳ یادآوری می‌کند مدارک دستی BLS و vintageهای دقیق خودکار تازه نمی‌شوند. اولویت، پیشنهاد خریدوفروش نیست.

هر مورد فایل ورودی و JSON Pointer دارد. `/steps/9` یعنی عنصر دهم steps؛ شماره از صفر شروع می‌شود. JSON تمام اختلاف‌ها و مسیر دو طرف را حفظ می‌کند؛ فارسی حداکثر ۱۵ نمونه نشان می‌دهد.

## اجرا بدون شبکه

```powershell
uv run gold review-refresh PATH_TO_REFRESH --baseline PATH_TO_REPORT_BUNDLE
uv run gold verify-review PATH_TO_REVIEW_BUNDLE
```

اولی گردش ذخیره‌شده را بررسی می‌کند، نه بازار امروز را. دومی هش، مقایسه، شمارش، اولویت و فارسی را از ورودی‌های همراه بازحساب می‌کند. سالم‌بودن بسته، حقیقت اقتصادی یا سودآوری را اثبات نمی‌کند.

## تمرین

1. COT با 403 شکست خورده و شاهد قبلی زیر حد سن است. دریافت جدید موفق نیست؛ سن و دریافت دو موضوع جدا هستند.
2. عددها ثابت‌اند و شناسه‌های والد تغییر کرده‌اند. گروه شاهد را بررسی کنید؛ مقدار تازه ادعا نمی‌شود.
3. horizon عوض شده و ردیف ناپدید شده است. حذف توسط ناشر ثابت نیست؛ ابتدا زمینه و خروج از نما را بررسی کنید.
4. گزارش امروز از دادهٔ دو روز قبل ساخته شده. زمان تولید گزارش، زمان دریافت یا دورهٔ مرجع را تازه نمی‌کند.

کد مرتبط `refresh_review.py` و comparator موجود است. [روش تحویل ۰٫۱۴](../source-methodology/refresh-review.fa.md) قرارداد و حدود بررسی را توضیح می‌دهد.
