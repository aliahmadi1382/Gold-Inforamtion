# Synthetic examples

`synthetic_prices.csv` and `synthetic_snapshot.json` are generated by `gold demo`.
Every numerical price is fictional. They demonstrate the input contract, calculations and traceable output; they are not downloaded gold prices. Run the demo to recreate their raw evidence and SQLite IDs locally. The snapshot intentionally marks unavailable context layers as missing.

Do not replace these fixtures with vendor data. Keep real examples under ignored `local/` and record provider/rights/coverage there.
