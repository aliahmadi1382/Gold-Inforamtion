# نتیجهٔ بررسی HistData

در ۸ اکتبر ۲۰۲۶ نمونهٔ رسمی XAU/USD ماه سپتامبر از مسیر Generic ASCII / M1 دریافت شد؛ حساب، پرداخت یا سرویس FTP استفاده نشد. [FAQ](https://www.histdata.com/f-a-q/) و [مشخصات فایل](https://www.histdata.com/f-a-q/data-files-detailed-specification/) برای استفاده در برنامه‌های پژوهشی، OHLC بر پایهٔ Bid و EST بدون تغییر ساعت تابستانی توضیح دارند. تبدیل صحیح زمان ثابت UTC−۵ است؛ استفاده از America/New_York در تابستان یک ساعت خطا ایجاد می‌کند. حجم صفر placeholder است، نه حجم واقعی بازار. حقوق بازنشر یا آموزش مدل از این صفحات استنتاج نشده است.

## نتیجهٔ فایل واقعی: رد ورود

فایل `HISTDATA_COM_ASCII_XAUUSD_M1202609.zip` و گزارش وضعیت جداگانه از صفحهٔ رسمی دانلود شدند. گزارش وضعیت دانلودشده بایت‌به‌بایت با فایل متن داخل ZIP برابر است. فایل CSV دارای ۲۹٬۳۲۱ ردیف و ۲۸٬۹۴۷ زمان دقیقه‌ای یکتا است: ۳۷۴ ردیف اضافی با زمان تکراری، ۱۸۷ برگشت در ترتیب زمان و ۳۴۴ گروه زمان تکراری با مقادیر متفاوت مشاهده شد. اولین گروه تکراری شامل ردیف ۳۰۶ با برچسب `20260901 050500` است. گزارش وضعیت ارائه‌دهنده شامل شکاف‌های tick است؛ این سند به‌تنهایی تعارض دقیقه‌ای را رفع نمی‌کند.

SHA-256 آرشیو:

`bcd087aa27bdebbd39a00edea0aaf2d230801be6f18f3806ab8d2317ebeebc5a`

نمونه و رسید خصوصی در `local/phase3-source-review/histdata/` هستند. رسید `audit.json` تعدادها، هش CSV/status/archive و ردیف‌های تمام گروه‌های تکراری را ثبت می‌کند؛ مقادیر خصوصی در Git نیستند. `validation_status=rejected` است. هیچ ردیفی حذف، مرتب، میانگین یا به‌عنوان نسخهٔ صحیح انتخاب نشده؛ هیچ داده‌ای وارد store اصلی نشده و بازده روزانه ساخته نشده است.

## بررسی قابل تکرار

```powershell
.venv/Scripts/python.exe -X utf8 scripts/inspect_histdata_export.py --archive local/phase3-source-review/histdata/HISTDATA_COM_ASCII_XAUUSD_M1202609.zip --status local/phase3-source-review/histdata/HISTDATA_COM_ASCII_XAUUSD_M1202609.txt --month 202609 --retrieved-at 2026-10-08T15:00:00+00:00 --output local/phase3-source-review/histdata/audit-repeat.json
```

برای زمان واقعی ثبت از مقدار `retrieved_at` رسید اصلی استفاده شود؛ زمان مثال برای بازتولید ساختار است و سند دریافت نیست. مقصد موجود بازنویسی نمی‌شود. parser پیش از پردازش، نام و تعداد اعضای ZIP، اندازهٔ بازشده و اتصال گزارش وضعیت را بررسی می‌کند. دقیقهٔ خارج از ماه، ترتیب نامعتبر، زمان غیر‌دقیقه‌ای، OHLC نامعتبر و حجم غیرصفرِ فاقد تعریف رد می‌شوند. مرز ماه فایل بر مبنای EST است؛ UTC روز اول از ساعت ۰۵ شروع می‌شود و به روز اول ماه بعد تا ۰۴:۵۹ امتداد دارد. بدون ماه‌های مجاور روزهای مرزی UTC کامل نیستند.

تعریف واحد قیمت، منبع بالادستی، تقویم تاریخی و سیاست اصلاحیه هنوز مشخص نشده‌اند. حتی اجازهٔ استفاده و منطقهٔ زمانی روشن، این فایل را مناسب پژوهش بازده نمی‌کند. تصمیم فعلی: رد همین فایل تا دریافت نسخهٔ اصلاح‌شده یا توضیح ارائه‌دهنده؛ این نتیجه به همهٔ فایل‌های HistData تعمیم داده نشده است.

Twelve Data هم بررسی مقدماتی شد: [صفحهٔ Commodity](https://twelvedata.com/exchanges/commodity?group=core) دسترسی Grow+/Venture+ را نشان می‌دهد؛ مسیر بدون هزینهٔ تأییدشدهٔ این پروژه محسوب نشده و حساب جدید ساخته نشده است. [مستندات API](https://twelvedata.com/docs) می‌گویند پارامتر timezone برای دادهٔ روزانه نادیده گرفته می‌شود؛ بنابراین UTC با افزودن پارامتر تضمین نمی‌شود.

قدم مؤثر بعدی، گرفتن پاسخ روش از منبع موجود Alpha یا توضیح تعارض فایل HistData است. [متن پرسش HistData](histdata-methodology-questions.md) آماده شده و ارسال نشده است. بررسی وب عمومی فعلی برای بستن فاز ۳ کافی نیست.
