# تحویل ۰٫۲۰ — بازیابی یکپارچهٔ شواهد شبکه

`backup-store` اکنون بستهٔ نسخهٔ ۲ شامل SQLite، تمام `raw/`، اسناد `runs/` و اسناد نهایی JSON در `transport/` می‌سازد. کلید، کد، تنظیمات، گزارش‌ها و ضمیمه‌های runtime و synthesis بیرون store همچنان جدا نگهداری می‌شوند. این دامنه، پشتیبان کل workspace نیست.

قراردادهای `BackupManifest` و `RestoreReceipt` نسخهٔ ۱ و Schemaهای آن‌ها حفظ شده‌اند؛ مدل‌های نسخهٔ ۲ و دو Schema تازه، تعداد اسناد transport را اضافه می‌کنند. بررسی و بازیابی نسخهٔ ۱ همان دامنهٔ قدیمی را دارند؛ برای دریافت‌های قدیمی شاهد HTTP ساخته نمی‌شود.

در نسخهٔ ۲، مجموعهٔ دقیق فایل‌ها، هش و اندازه و شمارش transport کنترل می‌شود. هر سند با مدل TransportEvidence، شناسهٔ نام فایل، SHA-256 بایت‌های سند دریافت و زمان مرتب تلاش‌ها داخل بازهٔ اجرای پایان‌یافته بررسی می‌شود. سند یتیم، خراب، مسیر فراری یا پیوند، شمارش جعلی و تغییر منبع حین کپی رد می‌شوند. هش مجدد سند ناسازگار، کنترل اتصال به دریافت را دور نمی‌زند. وضعیت شکست‌ها و `quota_status=not_measured` حفظ می‌شوند؛ نبود سند برای دریافت قدیمی به معنی نبود تلاش نیست.

SQLite Online Backup و قفل مشترک نویسنده‌ها همان روش تحویل ۰٫۱۵ هستند. انتشار بسته و store بازیابی‌شده فقط پس از بررسی انجام می‌شود. خطای کپی می‌تواند پوشهٔ `.incomplete-*` باقی بگذارد؛ مقصد باید تازه و بیرون store اصلی و بسته باشد. پایگاه فعلی بازنویسی نمی‌شود.

```powershell
uv run gold --store local/market backup-store --output-dir local/backups
uv run gold verify-backup PATH_TO_BACKUP
uv run gold restore-store PATH_TO_BACKUP --destination local/restore-tests/NEW_NAME
```

آزمون واقعی محلی: ۹۵٬۵۰۴ نسخه، ۹۸ خام، ۷۶ دریافت (۷۱ موفق و ۵ ناموفق) و ۱۱ سند HTTP حفظ شدند. پشتیبان در `local/backups/v020/`، بازیابی در `local/restore-tests/v020-20261008/store` و رسیدها در `local/integration-v020/` قرار دارند. ردیف‌ها و تمام بایت‌های raw/runs/transport بین منبع و مقصد برابرند. دریافت شبکهٔ تازه انجام نشده است.

این نسخه روی دیسک C است؛ نسخهٔ مستقل بیرون دستگاه هنوز تنظیم نشده است. گزارش‌های مستقل با verifier اختصاصی و ضمیمه‌هایشان جدا حفظ شوند. فاز ۵ برای شواهد سهمیه و محیط واقعی محاسبهٔ خارجی باز است؛ کار بعدی دروازهٔ قیمت روزانه و زمان انتشار است. [فصل بیست‌ویکم](../education/21-transport-recovery.fa.md) آموزش این تحویل است.
